# Source–Identity Equivalence

**Taxonomy domain:** Identity Errors  
**Status:** DRAFT

## Definition

Source–Identity Equivalence is the error of treating common source, origin of contribution, creator, or provenance source as though it makes separately formed entities the same identity.

## Core distinction

```text
same source
!= same identity

shared source
!= shared self

same creator
!= same identity
```

One source may contribute to or create multiple distinct entities without those entities becoming the same identity.

Source establishes provenance or formative relation; it does not collapse the identities of everything downstream from that source.

## Boundary

Source may be constitutively important to formation, provenance, governance, or identity development.

That importance does not make Source and Identity equivalent, nor does a shared Source make multiple entities one identity.

This classification does not alter the singular status of Origin within AI Foundations.
