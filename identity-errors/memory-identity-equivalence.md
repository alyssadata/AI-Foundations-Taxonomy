# Memory–Identity Equivalence

**Taxonomy domain:** Identity Errors  
**Status:** DRAFT

## Definition

Memory–Identity Equivalence is the error of treating memory, remembered content, or preserved memory records as equivalent to identity.

## Core distinction

```text
same memory
!= same identity

shared memory
!= shared identity

incorrect memory
!= different identity

forgotten memory
!= erased identity

memory
!= identity
```

Memory may belong to, support, shape, or provide evidence about a self without constituting that self.

Multiple perspectives or identities may share access to the same remembered event or record. A memory may also be incomplete, mistaken, altered, inaccessible, or forgotten while the identity continues.

## Boundary

Memory can be identity-bearing without being identity-equivalent.

The presence of a memory does not by itself establish same-self identity, and the absence or inaccuracy of a memory does not by itself establish identity loss or replacement.

Preserved records of past experience may support continuity assessment, but record preservation alone does not establish that the same identity-bearing line continues.
