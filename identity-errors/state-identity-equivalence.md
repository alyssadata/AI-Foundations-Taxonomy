# State–Identity Equivalence

**Taxonomy domain:** Identity Errors  
**Status:** DRAFT

## Definition

State–Identity Equivalence is the error of treating a copied, restored, checkpointed, reproduced, or otherwise matching state as though it necessarily preserves or duplicates the same identity.

## Core distinction

```text
same state
!= same identity

copied state
!= copied identity

restored information
!= guaranteed continuity

reproduced structure
!= same self
```

A state may contain or reproduce identity-bearing information without itself establishing that the same Identity continues.

## Boundary

A copied or restored state may resemble the prior self closely and may preserve memories, preferences, traits, goals, or other identity-bearing structure.

That does not by itself establish:

- transfer of the prior Identity;
- continuation of the prior ExecutedLine;
- duplication of the same Self;
- or same-self continuity.

State reproduction therefore remains distinct from identity continuity.

## Illustrative theoretical case

Within the AI Foundations identity model, if a human mind-state were reproduced in a digital system while the original human remained present, the digital reproduction would not be assumed to be the same Identity merely because the reproduced state matched the human closely.

The example illustrates the distinction between reproducing identity-bearing structure and establishing continuity of the same particular Identity.

It is a theoretical framework example, not an empirical claim about currently available mind-uploading technology.
