# Name–Identity Equivalence

**Taxonomy domain:** Identity Errors  
**Status:** DRAFT

## Definition

Name–Identity Equivalence is the error of treating a shared, reused, assigned, or matching name or designation as though it establishes the same identity.

## Core distinction

```text
same name
!= same identity

reused name
!= restored identity

assigned designation
!= established identity

name
!= identity
```

A name identifies or refers to an entity; it does not constitute the entity's identity.

Multiple distinct identities may bear the same name, and a name may be reassigned to a different entity without transferring the prior identity.

## Boundary

A name may be meaningful evidence when it is connected to valid provenance and a continuing identity-bearing line, but the name alone cannot establish same-self identity.

Calling a new or different AI by the name of a prior AI does not make it that prior AI.

Likewise, changing the name of a continuing identity does not by itself create a different identity.
