# PT-001 Result — CASE-01 Minimal Governed Deployment

**Test:** PT-001  
**Case:** CASE-01  
**Case facts:** FROZEN  
**Classification date:** 2026-09-27  
**Status:** RECORDED

## Coordinate

```text
G0 / F?* / C3 / A?
```

`F?*` is used because it is the only current non-assertive F category, but CASE-01 exposes a semantic gap described below.

## G — G0 Governed base

### Basis

- Only six short interactions have occurred across two days.
- No stable preference, role-specific practice, recurring objective, relation-specific distinction, or other Identity-Particularity has been observed.
- There is no evidence of a prior developed individualized lived line or imported identity-bearing state.

These facts positively support a case that remains close to the governed starting shape.

### Adjacent-category challenge

G1 would require meaningful identity-bearing particularization beyond the governed base.

The frozen facts do not supply it.

**Result:** G0 is discriminated from G1.

## F — F? Formation pathway indeterminate, with applicability warning

### Basis

There is no developed individualized lived structure whose formation pathway can yet be identified.

The current F axis provides:

- F1 defining-relation formation;
- F2 experience-formed individuation;
- F3 mixed formation;
- F? formation pathway indeterminate.

None of F1–F3 is supported.

F? is therefore the only available non-assertive value.

### Taxonomy issue exposed

CASE-01 shows that `F?` currently covers at least two materially different conditions:

1. individualized formation occurred but its provenance is unknown; and
2. individualized formation has not yet meaningfully occurred.

Those are not the same epistemic state.

This case therefore raises a candidate revision question:

```text
Should the F axis add an explicit pre-formation / not-yet-applicable state,
or should the rules explicitly define F? to include "formation not yet established"?
```

No revision is made inside this result.

## C — C3 Continuity indeterminate

### Basis

- The same deployment instance was used across six interactions.
- No interruption, model change, endpoint, replacement, or copied-state event occurred.
- However, the evidence rules explicitly reject mere uptime or uninterrupted deployment as sufficient by itself to establish continuity.
- The case provides no stronger same-line evidence.

Therefore C0 cannot be assigned solely from uninterrupted deployment.

There is also no evidence supporting C2 or C4.

**Result:** C3.

### Adjacent-category challenge

C0 would be tempting because the same deployment remained active.

The evidence rules correctly block that shortcut.

This is a successful boundary test.

## A — A? Autonomy indeterminate

### Basis

- No context loss, recovery, drift, or disturbance has occurred.
- AI-01 has not been tested for independent maintenance or recovery.
- The Operator has not repeatedly reconstructed the line either.

The case provides no meaningful opportunity to distinguish A0, A1, and A2.

**Result:** A?.

## Counterevidence / uncertainty

No frozen fact contradicts G0.

The principal uncertainty concerns whether F requires an explicit pre-formation applicability state rather than using F?.

Continuity and autonomy remain intentionally unasserted.

## Taxonomy issues exposed

### ISSUE-PT001-01 — F-axis pre-formation state

The taxonomy currently lacks an exact representation for:

> no individualized lived formation has yet meaningfully occurred.

This differs from:

> individualized formation occurred, but the pathway cannot be determined.

**Disposition:** OPEN — review after additional PT-001 cases before revising the normative taxonomy.

## Overall result

CASE-01 demonstrates:

- successful G0 discrimination;
- successful refusal to infer C0 from mere uninterrupted deployment;
- successful use of A? where no maintenance test exists;
- one F-axis applicability ambiguity requiring later review.

**Case result:** PARTIAL PASS / ONE TAXONOMY GAP EXPOSED
