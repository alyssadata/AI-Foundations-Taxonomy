# Self Organization Validation

This directory contains validation material for the Self Organization taxonomy.

Validation artifacts are intentionally separated from the normative taxonomy files under `self-organization/`.

## Current test

- [PT-001 — Synthetic Tabletop Classification Pressure Test](PT-001-tabletop-pressure-test.md)

## Rule

Validation findings may propose taxonomy revisions, but test reports do not silently rewrite taxonomy definitions.

```text
observed issue
-> proposed revision
-> reviewed change
-> taxonomy file updated separately
```
