# Response Organization

Response Organization classifies what kind of return, if any, follows when an object or system is affected by contact or interaction.

The domain separates **being affected** from **producing a response**, and separates both from claims of subjective experience.

## Current entries

- [Contact–Response Organization](contact-response-organization.md)

## Boundary

Response organization is an observable or structurally inferable classification.

A higher degree of response organization may justify stronger claims about internally generated processing, but it does not by itself establish phenomenal consciousness.
